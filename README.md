# Nayem Mia — Portfolio

Static website (single `index.html`). No build step.

## Deploy on GitHub Pages
1. Upload these files to a GitHub repository (root).
2. Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
3. Your site will be live at https://USERNAME.github.io/REPO/

## Editing content
Open `index.html`, find `<script id="data" type="application/json">` and edit the text
(name, bio, email, services, works, social links). The built-in Admin panel only works
inside Claude, not on GitHub Pages.
